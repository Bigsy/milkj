## Complete bundled dependency list

The editor UI is a Vite bundle, so the libraries named above ship together with roughly two hundred
further npm packages: the `unified` / `micromark` / `mdast` Markdown stack, d3 and its satellites by
way of mermaid, and assorted small utilities. They are MIT, ISC, BSD-3-Clause and Apache-2.0 licensed.

Every bundled package, including the ones named above, is listed with its exact version and its
license text as published in the MilkJ plugin artifact at `third-party/BUNDLED-LICENSES.md`. That
file is generated by `scripts/collect-third-party-licenses.mjs` (`make licenses`) from the bundle's
own source maps, so it describes the code that is actually redistributed rather than the declared
dependency list.
